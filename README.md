# استودیو صدور لایسنس دقیق (Daqiq License Generator Studio v1.1.0)
### Commercial Offline License Studio for Daqiq Desktop ERP (v4.9.0+)

**Daqiq License Generator v1.1.0** یک نرم‌افزار تجاری رده سازمانی، کاملاً آفلاین (Air-Gapped) و بازنویسی‌شده از پایه با زبان قدرتمند **Rust + Tauri v2** است که برای تولید، مدیریت، امضا و بازرسی لایسنس‌های نامتقارن رمزنگاری‌شده (`.daqlic`) نرم‌افزار **دقیق (Daqiq Desktop ERP v4.9.0 - PR #38)** توسعه یافته است.

---

## 🚀 ویژگی‌های کلیدی نسخه ۱.۱.۰ (Key Features)

1. **بازنویسی کامل با Rust و حذف پنجره کنسول (Zero CMD Window):**
   - فایل اجرایی کامپایل‌شده مستقیماً به عنوان ساب‌سیستم گرافیکی ویندوز (`subsystem = 2 / WINDOWS_GUI`) بدون هیچ‌گونه پرش یا نمایش پنجره CMD اجرا می‌شود.
   - حجم فایل پرتابل از ۲۸۷ مگابایت به **کمتر از ۲۰ مگابایت** کاهش یافته است.
   - شروع به کار آنی (کمتر از ۱ ثانیه) با مصرف رم ناچیز.
2. **تطابق صد در صدی با موتور امنیتی Daqiq PR #38:**
   - امضای دیجیتال استاندارد **Ed25519 (RFC 8032)** با کلیدهای ۳۲ بایتی Base64.
   - پیشوند تفکیک دامنه رمزنگاری: `b"DAQIQ-LICENSE-V1\n"`.
   - سریال‌سازی استاندارد و قطعی (Canonical JSON): نرمال‌سازی نویسه‌ها به فرم **Unicode NFC**، مرتب‌سازی الفبایی کلیدها در تمام سطوح شیء (`BTreeMap`) و جداسازهای استاندارد بدون فاصله `(,)` و `(:)`.
   - قفل سخت‌افزاری گره‌ها بر اساس استاندارد **`fp_v1:<64-hex>`** با پالایش خودکار نویسه‌های نامرئی، نیم‌فاصله‌ها و کاراکترهای جهت متن (RLM/LRM).
3. **گاوصندوق رمزنگاری‌شده کلیدهای امضا (Encrypted Key Vault):**
   - ذخیره‌سازی کلیدهای اختصاصی منحصراً به فرمت رمزنگاری‌شده `.dqvault` با الگوریتم **AES-256-GCM** و مشتق‌سازی کلید با **PBKDF2-HMAC-SHA256 (۶۰۰٬۰۰۰ دور تکرار)**.
   - پاک‌سازی امن رم با کتابخانه `zeroize` هنگام خروج از حافظه.
   - عدم ذخیره هیچ کلید حساسی به صورت متن آشکار (Plaintext) در مخزن Git.
4. **رابط کاربری چشم‌نواز، مدرن و کاملاً آفلاین (Offline Persian RTL):**
   - پشتیبانی از تم‌های تیره (Dark) و روشن (Light) منطبق بر استانداردهای کنتراست **WCAG AA+**.
   - قلم زیبای **وزیرمتن (Vazirmatn)** به صورت فایل‌های محلی WOFF2 درون برنامه تعبیه شده و بدون نیاز به اینترنت لود می‌شود.
   - چیدمان استاندارد راست‌به‌چپ (RTL) با فرمت‌های چپ‌به‌راست تک‌فاصله (Monospace) برای شناسه‌های فنی و کلیدها.
5. **دفتر ثبت فروش و بایگانی لایسنس‌ها (SQLite Ledger):**
   - پایگاه داده سبک و محلی SQLite برای جستجو و نگهداری سوابق لایسنس‌های مشتریان.
   - خروجی استاندارد CSV جهت وارد کردن به اکسل و سیستم‌های حسابداری.
6. **بازرس و شبیه‌ساز دقیق (Inspector & Simulator):**
   - امکان وارد کردن هر فایل `.daqlic`، راستی‌آزمایی امضا و محاسبه هش SHA-256.
   - شبیه‌ساز کامل رفتار ارزیابی نرم‌افزار دقیق برای بررسی تاریخ‌های انقضا، نسخه‌های مجاز و شناسه‌های سخت‌افزاری.
7. **اجرای خودکار آزمون‌های هِدلس و گزارش سلامت:**
   - پشتیبانی از پرچم `--self-test --report <path>` جهت تست داخلی تمام ماژول‌های رمزنگاری و ثبت نتیجه بدون باز شدن پنجره GUI.

## ⚙️ دستورات ساخت و تست (Build & Verification)

### اجرای آزمون‌های هسته رمزنگاری (Rust Test Suite)
```bash
cargo test --workspace --verbose
```

### اجرای تست سازگاری متقابل با Daqiq PR #38
```bash
python -m pytest tests/test_cross_repo_compatibility.py -v
```

### ساخت نسخه نهایی پرتابل (Standalone Release EXE)
```bash
cargo build --release -p daqiq-license-generator
```
فایل اجرایی در مسیر `target/release/daqiq-license-generator.exe` تولید می‌شود.

### اجرای آزمون سلامت هِدلس (Headless Self-Test)
```bash
.\target\release\daqiq-license-generator.exe --self-test --report selftest_report.json
```
