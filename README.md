# استودیو صدور لایسنس دقیق (Daqiq License Generator Studio v1.3.0)
### Commercial Offline License Studio for Daqiq Desktop ERP (v4.9.1+ — PR #39)
**100% Self-Contained Zero-WebView2 Native Rust Desktop Application**

**Daqiq License Generator v1.3.0** یک نرم‌افزار تجاری رده سازمانی، کاملاً آفلاین (Air-Gapped) و بازنویسی‌شده به‌صورت **۱۰۰٪ Native Rust خالص بدون هیچ‌گونه وابستگی به WebView2، مرورگر Edge یا مفسر پایتون** است. این ابزار با **تطابق دقیق ۱:۱ ("تطابق کامل. نه کمتر نه بیشتر")** با ساختار اعتبارسنجی **نرم‌افزار دقیق (Daqiq Desktop ERP v4.9.1 — PR #39)**، لایسنس‌های نامتقارن رمزنگاری‌شده (`.daqlic` و توکن‌های فشرده متنی Base64) را با نرخ فریم روان **60FPS و شتاب‌دهی سخت‌افزاری** تولید، مدیریت، امضا و بازرسی می‌کند.

---

## 🚀 ویژگی‌های کلیدی نسخه ۱.۳.۰ (Key Features)

1. **تطابق کامل ۱:۱ با موتور اعتبارسنجی Daqiq PR #39 (v4.9.1):**
   - پشتیبانی جامع و دقیق از تمامی فیلدها و انواع لایسنس جدید از جمله لایسنس **آزمایشی (Trial)**، **دوره‌های مهلت و لطف (Grace Periods - Soft & Hard)**، **سیاست‌های تطابق سخت‌افزاری (Match Policy)**، **تسامح ناهماهنگی ساعت سیستم (Clock Skew Tolerance)**، و **سهمیه‌ها (Quotas)**.
   - حذف کامل فیلدهای ساختگی یا خارج از مشخصات PR #39 و انطباق قطعی سریال‌سازی کلیدها (عدم درج فیلدهای اختیاری None در امضای دیجیتال).
   - تولید و مصرف مستقیم **توکن‌های فشرده متنی لایسنس (Compact Base64 Tokens)** علاوه بر فایل‌های استاندارند `.daqlic`.

2. **حل دائمی و ریشه‌ای خطای امضای دیجیتال (Permanent Signature Fix):**
   - تحلیل و رفع تضاد پیشین شناسه کلید و جفت‌کلیدهای نامعتبر با افزودن **ابزار تطابق جفت‌کلید عمومی (Public Key Pairing Verifier)** در نرم‌افزار.
   - تشخیص و نمایش آنی سازگاری کلید فعال گاوصندوق با کلید رسمی توکار نرم‌افزار دقیق (`daqiq-prod-v1: tZwFxuCGOF+WZqVF+PeKwpoIpOZovHLFRVSQxGaXJXA=`) بر اساس هش ۱۲ نویسه‌ای SHA-256.

3. **رابط کاربری مدرن با نرخ ۶۰ فریم و شتاب‌دهی سخت‌افزاری (60FPS Native UI):**
   - معماری رندرینگ مدرن **`iced`** مجهز به بک‌اند پرسرعت **`wgpu`** (DirectX 12 / Vulkan) با جابجایی خودکار به رندرر نرم‌افزاری **`tiny-skia`** در سیستم‌های بدون GPU.
   - حذف کامل هرگونه لگ، پرش یا استاتر هنگام اسکرول با پیاده‌سازی معماری Zero-Work `view()` و پیش‌محاسبه داده‌ها در فاز `update()`.
   - سایدبار راست‌چین (RTL) مدرن ۲۲۰ پیکسلی، با تم تیره زغالی ملایم و ارگونومیک (`#1E222B`) و تم روشن شفاف و استاندارد (`#F4F6FA`).

4. **حذف کامل WebView2 و استقلال مطلق (Zero WebView2 / Zero External Runtime):**
   - اجرای ۱۰۰٪ پایدار روی هر سیستم ویندوز ۱۰ یا ۱۱ بدون نیاز به نصب Edge، WebView2، کتابخانه‌های VC++ یا مفسر پایتون.
   - فایل اجرایی تک و پرتابل سبک (< ۲۵ مگابایت) و پیوند به ساب‌سیستم گرافیکی ویندوز (`Subsystem = 2 / IMAGE_SUBSYSTEM_WINDOWS_GUI`) بدون پرش پنجره کنسول (Zero CMD Window).

5. **گاوصندوق رمزنگاری‌شده کلیدهای امضا (Encrypted Key Vault):**
   - ذخیره‌سازی کلیدهای اختصاصی منحصراً به فرمت رمزنگاری‌شده `.dqvault` با الگوریتم **AES-256-GCM** و مشتق‌سازی کلید با **PBKDF2-HMAC-SHA256 (۶۰۰٬۰۰۰ دور تکرار)**.
   - پاک‌سازی امن حافظه با کتابخانه `zeroize`.
   - خط‌مشی سخت‌گیرانه عدم ثبت هیچ کلید خصوصی در مخزن گیت.

6. **قلم‌های محلی و شکل‌دهی بومی خط فارسی (Embedded Fonts & RTL Shaping):**
   - قلم‌های محلی **وزیرمتن (Vazirmatn)** و **جت‌برینز مونو (JetBrains Mono)** به صورت باینری با دستور `include_bytes!` درون فایل اجرایی تعبیه شده‌اند.
   - رندر و شکل‌دهی صحیح حروف متصل زبان فارسی به صورت بومی با موتور `cosmic-text` / `rustybuzz`.

7. **دفتر ثبت فروش و سوابق لایسنس‌ها (Bundled SQLite Ledger & Excel BOM):**
   - پایگاه داده محلی SQLite برای جستجو، فیلتر و نگهداری سوابق لایسنس‌های صادر شده.
   - دکمه تمدید و صدور سریع (`Clone & Renew`).
   - خروجی استاندارد CSV همراه با بایت نشانه ترتیبی **UTF-8 BOM (`\xEF\xBB\xBF`)** برای نمایش بدون نقص حروف فارسی در نرم‌افزار مایکروسافت اکسل.

8. **بازرس و شبیه‌ساز دقیق (Inspector & Simulator):**
   - بارگذاری و بازرسی فایل‌های `.daqlic` یا توکن‌های متنی Base64.
   - راستی‌آزمایی امضای دیجیتال و شبیه‌سازی وضعیت اعتبار با در نظر گرفتن تاریخ، شناسه سخت‌افزاری و نسخه اپلیکیشن.

9. **آزمون‌های خودکار و کنترل کیفیت پیوسته (Headless QA):**
   - پرچم `--self-test --report <path>` جهت تست داخلی تمام ماژول‌های رمزنگاری و شبیه‌ساز وضعیت بدون باز شدن پنجره گرافیکی.
   - پرچم `--version` جهت استعلام نسخه سریع.

## ⚙️ دستورات ساخت و تست (Build & Verification)

### ۱. اجرای آزمون‌های هسته پردازشی
```bash
cargo test -p daqiq-lic-core --no-default-features
```

### ۲. اجرای تست سازگاری متقابل با Daqiq PR #39
```bash
python -m pytest tests/test_cross_repo_compatibility.py -v
```

### ۳. ساخت نسخه نهایی پرتابل (Standalone Release EXE)
```bash
cargo build --release -p daqiq-license-generator
```

### ۴. بازرسی خودکار هدر PE و عدم وابستگی به WebView2
```bash
python scripts/verify_pe.py target/release/daqiq-license-generator.exe 25.0
```

### ۵. اجرای آزمون سلامت هِدلس (Headless Self-Test)
```bash
.\target\release\daqiq-license-generator.exe --self-test --report dist\selftest_report.json
```

## 🔒 امنیت و گواهی انطباق (Security Compliance)

- **Air-Gapped & 100% Offline:** صفر اتصال شبکه‌ای در زمان اجرا؛ تمام قلم‌ها و دارایی‌ها مستقیماً درون باینری تعبیه شده‌اند.
- **Zero Secrets in Git:** هیچ کلید خصوصی متن آشکاری در مخزن وجود ندارد؛ آزمون‌ها با کلیدهای گذرا اجرا می‌شوند.
- **PE GUI Subsystem 2:** بدون وابستگی به کنسول ویندوز یا خط فرمان (عدم نمایش پنجره سیاه CMD).
- **Public Key Pairing Assurance:** تضمین ریاضی عدم مغایرت کلید امضا با موتور امنیتی Daqiq قبل از صدور لایسنس تجاری.
